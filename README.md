# 浮生南北 · Mbusreng-Nempek

南北多故，人生未定。这是一个魏晋南北朝人物人生模拟项目。

眼下先立章程、备史料，尚无可运行的游戏代码。

## 命名缘由

中文名为 **《浮生南北》**，副标题为「魔法晋书目录」。故事落在一个充满魔法的东晋十六国：从一人出生写起，看他如何成长、如何抉择，也看这纷扰世道怎样改变他的命运。

拉丁字母名称 **Mbusreng-Nempek** 取白一平—沙加尔（Baxter–Sagart）上古汉语拟音，略作简写：

| 字 | 上古拟音 | 项目拼写 |
| --- | --- | --- |
| 浮 | `*m.b(r)u` | `Mbu` |
| 生 | `*sreŋ` | `sreng` |
| 南 | `*nˤ[ə]m` | `Nem` |
| 北 | `*pˤək` | `pek` |

拼写时，`ŋ` 写作 `ng`，`ə` 写作 `e`，拟构标记、音节分隔符与特殊符号一并略去；「浮」取不带可选 `r` 的形式。四字合写，便是 `Mbusreng-Nempek`，用于项目命名。

拟音依据：[白一平—沙加尔上古音拟构表，2014-09-20，版本 1.1](https://sites.lsa.umich.edu/ocbaxtersagart/wp-content/uploads/sites/1415/2025/03/BaxterSagartOCbyMandarinMC2014-09-20.pdf)。
