# 浮生南北 · Mbusreng-Nempek

魏晋南北朝人物人生模拟项目。

当前处于设计与史料准备阶段，仓库尚无可运行的游戏代码。

## 命名缘由

中文名为 **《浮生南北》**，副标题为「魔法晋书目录」。写个人一生在充满魔法的东晋十六国的际遇与抉择，从一个人的视角，经历出身、成长与选择，以及历史如何改变其命运。

拉丁字母名称 **Mbusreng-Nempek** 取自白一平—沙加尔（Baxter–Sagart）上古汉语拟音的简化拼写：

| 字 | 上古拟音 | 项目拼写 |
| --- | --- | --- |
| 浮 | `*m.b(r)u` | `Mbu` |
| 生 | `*sreŋ` | `sreng` |
| 南 | `*nˤ[ə]m` | `Nem` |
| 北 | `*pˤək` | `pek` |

拼写将 `ŋ` 写作 `ng`、`ə` 写作 `e`，省略拟构标记、音节分隔符与特殊符号；「浮」采用不带可选 `r` 的形式。四字合写为 `Mbusreng-Nempek`。这是用于项目命名的简化形式。

拟音依据：[白一平—沙加尔上古音拟构表，2014-09-20，版本 1.1](https://sites.lsa.umich.edu/ocbaxtersagart/wp-content/uploads/sites/1415/2025/03/BaxterSagartOCbyMandarinMC2014-09-20.pdf)。
