# 三道相性与诡道数值设计

人各有其性，临事也未必一成不变。人物用**相性角 x**和**稳定度 r**共同描述：角度定王道、霸道、我道的倾向，离圆心的距离定行为有多稳定。越近圆心，行事越多变；正圆心则记为诡道。

立此章程于2026年10月17日。本版先定坐标、三道主辅与诡道的判法。

## 三道各有所居

| 项目 | 定义 |
| --- | --- |
| 相性角 x | 0 ≤ x < 120，整圈为120，120与0重合 |
| 三道中心 | 王道30、霸道70、我道110，相邻中心间隔40 |
| 稳定度 r | 0 ≤ r ≤ 100；0位于圆心，100位于外缘 |
| 多变度 v | v = 100 − r；越大，行为越多变 |

图从顶端0起，顺时针递增。倾向与稳定度各记各的：即便纯属王道，行事也可能颇为多变。

## 主辅判定

先看稳定度，再论三道。**r = 0便直接判为诡道，不分三道主辅**；r > 0，再依下列角度判定。

角度归一化：`x = ((x % 120) + 120) % 120`。

人物离某一道中心 c 有多远，取圆周上的最短距离：`d(x, c) = min(abs(x − c), 120 − abs(x − c))`。

分别算到30、70、110的距离，由近到远排好。最近者记 d₁，次近者记 d₂。

| 条件 | 分类 |
| --- | --- |
| d₁ < 10 | 纯最近道 |
| 10 ≤ d₁ < 20 | 最近道为主，次近道为辅 |
| d₁ = d₂ = 20 | 两道并重，不分主辅 |

最近中心距离至多为20。10、50、90三处是并重点。距离恰好为10，算主辅；恰好为20，算并重，端点不可混记。

## 其性有常，行事有变

稳定度 r 记人物有多依循惯常倾向。两人相性角相同，r较大者行事更稳定，r较小者更容易变化。

到了正圆心，极角已无确定意义，故r = 0时只显示“诡道”。r > 0，仍保留三道倾向，同时显示稳定度或多变度。

多变度先用0至100作描述刻度。它究竟怎样影响事件概率、怎样改变决策偏离幅度，尚未定式。

## 边界与示例

| 相性角 x | 稳定度 r | 倾向分类 | 多变度 |
| --- | --- | --- | --- |
| 30 | 100 | 纯王道 | 0 |
| 40 | 100 | 王道为主，霸道为辅 | 0 |
| 50 | 100 | 王道与霸道并重 | 0 |
| 60 | 100 | 霸道为主，王道为辅 | 0 |
| 0或120 | 100 | 我道为主，王道为辅 | 0 |
| 30 | 51 | 纯王道倾向，行为具有多变性 | 49 |
| 不参与判定 | 0 | 诡道，无固定主道 | 100 |

以上只演示判法，人物出生时并不照此分配数值。
