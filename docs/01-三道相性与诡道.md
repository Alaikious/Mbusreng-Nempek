# 三道相性与诡道数值设计

人物由**相性角 x**和**稳定度 r**共同描述：角度决定王道、霸道、我道的倾向；离圆心的距离决定行为稳定程度。越接近圆心，行为越多变；圆心代表诡道。

记录日期：2026年10月17日。本版确定坐标体系、主辅分类和诡道规则。

## 坐标与数值

| 项目 | 定义 |
| --- | --- |
| 相性角 x | 0 ≤ x < 120，整圈为120，120与0重合 |
| 三道中心 | 王道30、霸道70、我道110，相邻中心间隔40 |
| 稳定度 r | 0 ≤ r ≤ 100；0位于圆心，100位于外缘 |
| 多变度 v | v = 100 − r；越大，行为越多变 |

图中从顶端0开始，顺时针增加相性角。角度倾向与稳定度相互独立：纯王道倾向也可以具有较高的多变度。

## 主辅判定

先判断稳定度。**r = 0时直接判为诡道，不判三道主辅**；r > 0时，按下面的角度规则分类。

角度归一化：`x = ((x % 120) + 120) % 120`。

人物与某一道中心 c 的距离，取圆周上的最短距离：`d(x, c) = min(abs(x − c), 120 − abs(x − c))`。

分别计算到30、70、110的距离，按从近到远排序。令最近距离为 d₁，次近距离为 d₂。

| 条件 | 分类 |
| --- | --- |
| d₁ < 10 | 纯最近道 |
| 10 ≤ d₁ < 20 | 最近道为主，次近道为辅 |
| d₁ = d₂ = 20 | 两道并重，不分主辅 |

最近中心距离最大为20。三个并重点是10、50、90。恰好距离10归主辅区，恰好距离20归并重。

## 诡道与行为多变

稳定度 r 表示行为遵循惯常倾向的稳定程度。相性角相同的两个人，r较大者行为更稳定，r较小者行为更多变。

正圆心的极角没有确定意义，因此r = 0时只显示“诡道”。r > 0时，保留三道倾向，并同时显示稳定度或多变度。

多变度是0至100的描述刻度；它与具体事件概率、决策偏离幅度之间的映射尚待设计。

## 边界与示例

| 相性角 x | 稳定度 r | 倾向分类 | 多变度 |
| --- | --- | --- | --- |
| 30 | 100 | 纯王道 | 0 |
| 40 | 100 | 王道为主，霸道为辅 | 0 |
| 50 | 100 | 王道与霸道并重 | 0 |
| 60 | 100 | 霸道为主，王道为辅 | 0 |
| 0或120 | 100 | 我道为主，王道为辅 | 0 |
| 30 | 51 | 纯王道倾向，行为具有多变性 | 49 |
| 不参与判定 | 0 | 诡道，无固定主道 | 100 |

上述均为规则示例，不构成人物初始值。
