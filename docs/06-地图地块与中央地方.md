# 地图地块与中央地方

地块按当时的区划或地域划分。地方沿用当地名称；设有中央的地块，以当地核心城市命名中央，有些地方为了游戏性就做了稍微处理。

记录日期：2026-10-17。对应[剧本一：苻坚上位，淝水之战](./05-剧本一-苻坚上位，淝水之战.md)。

## 命名与划分

- 地块通常使用一个字的简称；关中、交广均以完整的双字名称作为简称。
- 交广由广州、交州合并，中央为番禺。
- 关中由雍州、秦州合并，中央为长安。
- 宁州、徐州不设中央，保留简称和地方名称。
- 西域、仇池为特殊地区，不设简称，也不分中央、地方。

## 355年下半年：势力与人物归属查证表

查证日期：2026-10-17。本节记录历史控制关系。以下沿用史籍的农历月份，以永和十一年秋七月前后为开局参照；本年下半年的变化另列。

### 归属处理

- 按实际控制的城市、地域安排人物，不凭刺史、州牧或都督的官号直接安排地块。
- 中央和地方由同一势力、同一人控制时，两栏可以相同；存在不同控制者时分别列出。
- 同一栏可以有多个势力、多人，并注明各自据点；不因一个人占有某处，就认定他控制整块地方。
- **按用户最新口径：有任期、无独立倾向的地方官，不单列为地图归属人物，只填所属势力的掌权者。** 地方官姓名、驻地与任期放入查证说明；有实际割据、自立或军政自主证据者才保留个人归属。受不同政权官号不等于由那些政权实际直接控制。
- 史料未能确认的中央，人物归属暂空，标为“待核”。“待核”不表示无人控制，也不表示已证实中央空置。
- 已确认势力归属的地点，不因守将或地方官失载而继续留空。只有势力归属本身也不清楚的地点，才保留配置待核；不据此宣称已经查齐所有郡县官员。

355年的东晋皇帝为司马聃；下表通常填写实际中枢掌权者褚蒜子、司马昱。桓温另有明确的地方军政自主证据，保留其荆州归属。普通官员的任职记录不自动构成新的势力或独立人物配置。[史20][史11]

现有地图只有地块名称，尚未逐郡划定边界。表内保留实际据点；跨州、改隶及地图覆盖不明的地方不强行归并。

六项状态：**四项按已确认势力归属落实配置；晋阳一项按张平连续控制作推定配置；廩丘一项保留势力归属待核。** 江州、宁州的355年刺史姓名仍属尚未解决的史学问题，不改写为已经查明。

### 半年内的更替与冲突

本表为历史时间注记，不是新增剧情。月份以《资治通鉴》为主；异书记载保留，不强行合成同一天。

| 时间 | 地点 | 实际变化 | 对归属的影响 |
| --- | --- | --- | --- |
| 七月至闰月间 | 枹罕—姑臧 | 张瓘起兵反张祚；宋混、宋澄响应；张祚被杀，张玄靓被立，张瓘进姑臧执政 | 凉州中央由张祚改为张玄靓名义统治、张瓘实际掌权，宋混参与执政；张瓘由地方起兵者转为中央执政者。不能将其两个阶段同时填写。[史1][史6] |
| 政变之后 | 陇西 | 李俨据郡，不受张瓘命，使用东晋年号 | 在关中地方另列李俨集团（奉晋），不与前凉的直接行政控制混同。[史1] |
| 政变之后 | 西平 | 卫綝据郡反张瓘，张琚击败卫綝 | 反叛、交战、战后控制应区分；张琚获胜不自动证明长期出任西平主官。[史1] |
| 政变之后 | 酒泉 | 太守马基起兵响应卫綝，张瓘遣张姚、王国击斩马基 | 不再把马基填作战后酒泉控制者；张姚、王国的军事行动也不自动等同永久驻守。[史1] |
| 八月 | 蒲坂 | 苻安被征入朝领太尉；苻柳任并州牧、镇蒲坂 | 司州地方的蒲坂记录由苻安改为苻柳；苻柳不因官号而移到晋阳。[史1][史2][史17] |
| 八月 | 陕城 | 苻廋任豫州牧、镇陕城 | 归入陕城实际所在地域，不填成许昌的中央控制者。[史1][史17] |
| 九月至十二月 | 长安 | 毛贵、梁楞、梁安等被杀；辛牢、赵韶、董荣、赵诲职权调整；雷弱儿亦被杀 | 前秦君主始终是苻生；辅政、近臣名单须按时点，不将死者保留为全年掌权人物。[史1][史4] |
| 十月 | 谢尚移镇 | 《晋书·穆帝纪》《宋书·州郡志》记马头，《通鉴》记寿春 | 两种记载并存。可确认其负责淮南前线，尚不能仅据这些记录判定月内行程或同一时刻驻地。[史1][史3][史13] |
| 十一月至十二月 | 黄河北岸—广固方向 | 慕容恪、阳骛奉命伐段龛，准备渡河 | 不改变355年广固仍属段龛的归属；不将356年战果提前。[史1] |
| 十二月 | 上党安民城 | 冯鸯逐守将、自称太守，向晋请降 | 并州地方新增冯鸯据点。《通鉴》称逐燕太守段刚，《晋书·穆帝纪》记背苻生，两书记法不同；不能据“请降”就认定晋朝廷已经直接接管该城。[史1][史3] |

前凉更替时间也有异记：《晋书·穆帝纪》系于秋七月；《通鉴》分述七月、八月、闰月诸事。因此本表不擅自选定某一公历日作为唯一开局状态。

| 势力／人物 | 据点或地域 | 暂缓原因 |

| 高昌集团／高昌 | 后来明确见白马、东燕 | 359年以前后据点可考，但不能凭较晚记录精确恢复355年的控制边界；暂列兖州地方候选。[史1][史3] |

| 吐谷浑／碎奚 | 青海及周边 | 君主可确认，但现有地块没有明确覆盖范围，不自行新增特殊地区，也不直接并入凉州。[史19] |
