# 资产数值设计

粮钱要记，部众也要记。资产分兵粮、金钱、士兵三项；士兵又分数量与质量两个数值。兵多是一回事，兵精又是一回事。

立此章程于2026-10-17。资产分类与士兵数量、质量的范围已定；计量单位、初始分配、收支和战力公式，尚未定式。

## 资产结构

| 资产 | 记录数值 | 用途 |
| --- | --- | --- |
| 兵粮 | 兵粮存量 | 军队供给及相关事件的资源条件 |
| 金钱 | 金钱存量 | 招募、供养及其他开支的资源条件，具体支出项目待定 |
| 士兵 | 士兵数量 | 人物掌握的士兵人数 |
| 士兵 | 士兵质量 | 部队整体作战素质，质量所包含的具体因素待定 |

士兵数量用非负整数，质量用 0–100，两端都算。二者各自记账，增减人数与改变质量，可以由不同事件引起。

## 与现有能力规则的联系

统帅管军队掌控、训练效果与战术能力；魅力管征兵和组织个人武装。等资产事件接入这些能力，再定能募多少人、训练能提高多少质量、又须耗费多少资源。

参考：[人物能力成长与终身提携](./02-人物能力成长与终身提携.md)。

## 待定参数

| 项目 | 待定内容 |
| --- | --- |
| 兵粮 | 计量单位、初始存量、获取方式、消耗周期及缺粮后果 |
| 金钱 | 计量单位、初始存量、收入与支出项目 |
| 士兵数量 | 初始人数、招募与损失规则、可统领人数上限 |
| 士兵质量 | 初始值、训练提升与衰退规则 |
| 军队事件 | 数量、质量与统帅如何共同影响事件结果 |
