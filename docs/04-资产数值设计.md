# 资产数值设计

资产分为兵粮、金钱、士兵三项；士兵包含数量和质量两个数值。

记录日期：2026-10-17。已确定资产分类及士兵数量、质量的取值范围；资产计量单位、初始分配、收支和战力公式尚待细化。

## 资产结构

| 资产 | 记录数值 | 用途 |
| --- | --- | --- |
| 兵粮 | 兵粮存量 | 军队供给及相关事件的资源条件 |
| 金钱 | 金钱存量 | 招募、供养及其他开支的资源条件，具体支出项目待定 |
| 士兵 | 士兵数量 | 人物掌握的士兵人数 |
| 士兵 | 士兵质量 | 部队整体作战素质，质量所包含的具体因素待定 |

士兵数量使用非负整数；士兵质量取值为 0–100，包含两端。两者分别记录，数量变化和质量变化可以由不同事件触发。

## 与现有能力规则的联系

统帅影响军队掌控、训练效果和战术能力；魅力影响征兵与组织个人武装。后续资产事件接入这些能力时，再确定招募数量、训练后的质量变化和资源消耗。

参考：[人物能力成长与终身提携](./02-人物能力成长与终身提携.md)。

## 待定参数

| 项目 | 待定内容 |
| --- | --- |
| 兵粮 | 计量单位、初始存量、获取方式、消耗周期及缺粮后果 |
| 金钱 | 计量单位、初始存量、收入与支出项目 |
| 士兵数量 | 初始人数、招募与损失规则、可统领人数上限 |
| 士兵质量 | 初始值、训练提升与衰退规则 |
| 军队事件 | 数量、质量与统帅如何共同影响事件结果 |
