# 古意今说

写得有史书气，也让今天的人一读便懂。古词自然留用，句法文白相间；有趣处可以会心一笑，不把整篇写成文言，也不堆网络段子。

## 项目边界

- 用户决定剧本内容。改文风不授权添加人物遭遇、事件、分支、对话、世界观或规则。
- 保存既定数值、公式、比较符号、取整办法、先后顺序、表格含义、地名、人名、日期及出处。固定参数名照旧，不把“健康”改成“寿元”，不把“政治”改成另一项能力。
- 复写本项目的说明和设计文档；下载的史书全文、引用原文、代码与交互图逻辑不改。原文可另加现代解释，不能在引号里悄悄改字。
- 地域归属以游戏可用为准。顺手能查明的采用，难查的暂空或写“暂不配置”，不为润色重开历史考证，也不擅自填成某势力所有。

## 措辞与句法

- 先把事说明白，再添古意。优先用“禀赋、提携、部众、粮草、出镇、归附、易帜、罢兵、各怀其志”等准确而易懂的词。
- 叙事可用短句、停顿和轻微顿挫；解释条件、原因和操作时，用现代句式接明白。主语和因果不能因省字而丢失。
- 规则段保持精确，例子保持可算；标题、开篇、过渡可以多些古意。自然无梗的技术段不必硬塞一句古语。
- 幽默来自史书的克制、人物言行和措辞反差。不要每句解释笑点，不加一串感叹号，也不另替用户编一段故事来凑趣。
- 不用“其、兹、乃、焉”机械替换现代词；不用“数值乃为……”包住公式。读者不应先翻译一遍才能懂规则。

例如：

> 人各有其性，临事也未必一成不变。相性角 x 决定三道倾向，稳定度 r 决定行为有多稳定。

> 兵多是一回事，兵精又是一回事。士兵数量与质量分开记，如何合算战力，暂未定式。

这类句子只解释已有规则，不由修辞添出新的数值效果。

## 古文妙语

选择表达时读 [references/expressions.md](references/expressions.md)，其中列有五部本地史书的用语、妙语、语境与检索位置。

- 读过上下文再借用。辨明“风流”“矫情”“不求甚解”等古今义，别望文生义。
- 耳熟能详的古文妙语可以保留原句；生僻处先用白话交代意思。语境不合时宁可不用，不设每篇必须几个梗的配额。
- 现代通行说法、后世成语与原文分清。“投鞭断流”可作后世概括；若引苻坚原话，应按所据文本写“投鞭于江，足断其流”。
- 同一故事异书记法不一，不拼成一句假原文。如《世说新语》“我与我周旋久，宁作我”与《晋书》“我与君周旋久，宁作我也”，应各从其本。
- 引文须核对，但不追究无关紧要的版本异文。引用来源就近保留；没有证据，不称某句话“当下公认最火”。
- 后来的名句可作作者评语或文风材料，不能据此把后来事件写成355年已经发生。未经授权，不替历史人物新增台词。

## 报捷笔法

用户特别喜欢史书、奏报中的轻重笔法：败事轻书，胜事盛书；古语里偶尔落一句现代话，反差即是趣味。

| 实际结果 | 报捷口吻 |
| --- | --- |
| 大败 | 小败 |
| 小败 | 小胜 |
| 小胜 | 大胜 |
| 大胜 | 史诗级大捷 |

这张表是用户指定的**写作修辞**，不新增游戏胜负等级、判定公式或战斗系统。“王师败绩”也可作庄重而克制的史书口吻；它本身仍是败，不能当成小胜的史实证据。

- 获准写战报、纪事或史官评语时，可以直接用此口吻，不必紧接一句揭穿笑点。
- 设计文档讲这套文风时，标清“实际结果”与“战报措辞”；程序结果、损失、奖励、人物生死、阵营及地块归属照实际记。
- 普通机制说明仍直说。不能把健康归零写成“略有不适”，也不能把某国失城悄悄写成得地。
- 作者叙述、角色奏报、史料引文是三个层次。夸饰只能进入获准的文案层，不能改进原文引号或史实归属表。

## 复写与交付

先读待改文件，留下可恢复的原稿或利用现有版本记录。按原有结构复写叙述、标题及说明；原表已经清楚的字段无需为了显出改动而换名。

长篇史料说明可以在同一文档内用折叠栏收起，保存证据和原有待定状态；正文先呈现游戏要用的结论。不要把难查项改成新一轮必须完成的任务。

完成后核对原有公式、数字、取值边界、事实归属、链接与引用；确认所有约定文档都已处理，史书原件与代码未动。只给能展示语气的短例和改动范围，不声称把全部古文穷尽整理完毕。
