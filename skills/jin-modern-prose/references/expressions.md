# 史书用语与妙语

取材自《浮生南北》项目 `downloads/` 的《晋书》《魏书》《十六国春秋》《资治通鉴》《世说新语》。五部均已作全文检索；这是写作选材，不是穷尽古语的词典。行号对应2026-10-18检索时的本地文本，可配合关键词定位。原文件含繁简、异体和录入差异；下列短句有标点整理，未据此改动原件。

## 先取其词气

| 表达 | 本地检索线索 | 怎么写得明白 |
| --- | --- | --- |
| 王师败绩 | 《晋书》卷八；检索“王师败绩” | 可用于战事评语。语气庄重，内容仍是官军战败，不自带“小败”含义。 |
| 兵粮、部众 | 《十六国春秋》卷二十六，409行“兵粮”；《魏书》1688行“部众” | 供给用“兵粮”，所统兵众用“部众”。固定资产名“兵粮”照旧。 |
| 出镇、归附、易帜 | 在五书中按词及“镇”“降”等相关表述检索 | 谁到哪里掌军、谁投向哪方，要写出来。“受封”与“实际控制”不可混用。 |
| 羁縻自固 | 《十六国春秋》卷二十七，420行；《晋书·慕容儁载记》同类记载 | 可写“官号照受，部众仍由自己掌握”，适合说明多头受封、实际自立。 |
| 诸部骚动，人心顾望 | 《魏书·太祖纪》，261行 | 各部不安，人们还在观望。不是已经全面起兵。 |
| 进退失据 | 《十六国春秋》171行；《通鉴》5757行 | 退路与据点都出了问题。后接具体处境，不靠四字词包办因果。 |
| 提携 | 《魏书》1622行“提携道趣” | 可留其相助、带携之意；本项目的能力提携已有公式，不能由古义另造机制。 |
| 禀赋、声望、穷达、盛衰 | 史传常用词气；注意“禀赋”也可能指发放粮食 | 可作叙述用词。参数仍叫既定的能力、潜质、威望，不能随笔改名。 |

## 妙语：用在合适处

| 表达 | 出处与定位 | 适合什么语气；有什么限度 |
| --- | --- | --- |
| 何不食肉糜？ | 《晋书》卷四《惠帝纪》，246行；《通鉴》卷八十三，7089行 | 用来讽刺不知现实艰难、说话脱离处境。不能拿来嘲笑饥民或把“肉糜”当普通军粮术语。 |
| 我与我周旋久，宁作我 | 《世说新语·品藻》，588行 | 自有其性，不必事事与人比高下。不是任何场景都可套的自恋台词。 |
| 我与君周旋久，宁作我也 | 《晋书》卷七十七《殷浩传》，6118行 | 与上条是异书记法，不混引。 |
| 时无英雄，使竖子成名！ | 《晋书》卷四十九《阮籍传》，4495行 | 带锋芒的讥评。不能让规则文档顺手把某个人评成无能。 |
| 未能免俗，聊复尔耳！ | 《晋书》卷四十九《阮咸传》，4499行 | 明知如此，姑且也随俗一回；适合轻微自嘲，不是所有待定事项的万能句。 |
| 本乘兴而行，兴尽而反 | 《晋书》卷八十《王徽之传》，6269行；《世说新语·任诞》876行“吾本乗兴而行兴尽而返” | 兴致来便去，尽了便返。各从所据文本，不把“反／返”差异当成新考据任务。 |
| 亲卿爱卿，是以卿卿；我不卿卿，谁当卿卿？ | 《世说新语·惑溺》，1074行 | 原是夫妻亲昵相称，有趣在直白；不塞进军事或数值条款。 |
| 咄咄怪事 | 《晋书》卷七十七《殷浩传》，6119行；《世说新语·排调》，1002行 | 说不出口的郁愤与不解，轻写也有意味；不把它当错误日志的唯一说明。 |
| 木犹如此，人何以堪！ | 《晋书》卷九十八《桓温传》，7399行；《世说新语·言语》，119行 | 感叹岁月与人事，适合人生题材；不擅自给现有剧本增加衰老事件。 |
| 小儿辈遂已破贼 | 《晋书》卷七十九《谢安传》，6191行；《通鉴》卷一百五，9248行 | 胜事轻说的故作镇定。《世说新语》396行则作“小儿辈大破贼”，不拼成同一句原文。 |
| 投鞭于江，足断其流 | 《晋书》卷一百一十四《苻坚载记下》，8204行；《十六国春秋》582行；《通鉴》卷一百四，9221行 | 兵众而自恃，可作夸口的反讽。“投鞭断流”是常见概括，不伪作逐字原话。 |
| 风声鹤唳 | 《晋书》6207行；《十六国春秋》583行；《通鉴》卷一百五，9245行 | 已惊惧至极，连风声鸟鸣也当追兵。不是“敌军真的到了”的证据。 |
| 闻鸡起舞 | 《通鉴》卷八十八，7567行记“中夜闻鸡鸣……因起舞”；《晋书·祖逖传》有本事 | 可概括勤勉奋发；不是诸事都要设成早起训练。 |
| 枕戈待旦 | 《世说新语》471行注引刘琨书；《通鉴》卷九十五，8154行 | 整装待战、心存恢复之志。用在军政语境，普通文档校对无需如此声势。 |
| 好读书，不求甚解，每有会意，欣然忘食 | 《晋书》卷九十四《陶潜传》，7134行 | 读书得其会心，不宜直接解成糊弄规则。本项目“难查暂置”应直说，不靠这句代替说明。 |

## 现代传播与用户指定的趣味

“何不食肉糜”已有明确的现代讽刺、网络用梗记录，可见[21财经谈网络梗文化](https://m.21jingji.com/article/20201120/herald/8ebd7dc92ce0edfcbc5c29c8bc958ebd.html)。其余上列首先作为有趣、可读的古文材料，不一概宣称当下流行，更不为了热度逐句搜榜。

用户指定的报捷措辞：**大败→小败，小败→小胜，小胜→大胜，大胜→史诗级大捷**。这是现代反讽写法，不声称出自任何一部古籍。用于获准的战报文案；设计与内部记录标明实际结果，不改损失和归属。没有战斗机制的文档，不由此增造一套战斗系统。

## 复写对照

| 原说明 | 文风示例 |
| --- | --- |
| 当前没有可运行的游戏代码。 | 眼下先立章程、备史料，游戏尚未开跑。 |
| 能力上限固定，不随当前能力提高。 | 禀赋先定，长进有界。当前能力涨了，上限不会跟着抬高。 |
| 稳定度为零时不判断三道。 | 到了正圆心，便只记诡道，不再论三道主辅。 |
| 士兵数量和质量分别记录。 | 兵多是一回事，兵精又是一回事。数量与质量，分开记。 |
| 该地区归属难以确认。 | 此地归属暂且留白，不为一处疑案耽误游戏。 |

示例是作者说明，不是历史人物原话。采用时仍以文档既有设定为准。
